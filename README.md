# Expedição Sistema Solar — 5º Ano

Jogo educativo da **WM Jogos Educativos** para exploração introdutória do Sistema Solar.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` e `README.md` para a raiz do repositório.
3. Em **Settings → Pages**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve. O GitHub fornecerá o endereço público do jogo.

## Netlify
Também é possível arrastar a pasta do projeto para um deploy manual no Netlify.

## Conteúdo
- Exploração dos planetas
- Missão com rover em Marte
- Cinturão de asteroides
- Combustível, XP e coleta de amostras
- Conceitos introdutórios do Sistema Solar
